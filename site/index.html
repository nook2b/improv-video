improv-video

improv-video is a personal macOS app that uploads rehearsal videos of my improv theatre group to my own YouTube channel.

When I insert the memory card of my Insta360 camera, the app copies the new clips, joins them into one video per day, applies color correction and audio clean-up on my computer, and uploads the video to YouTube as an unlisted video, so that only members of my group who receive the link can watch it.

Uses YouTube API Services

improv-video uses YouTube API Services (YouTube Data API v3, method videos.insert, OAuth scope youtube.upload) to upload videos to the signed-in user's own YouTube channel. It does not read, analyse or store any other YouTube data.
